01
5/07（四）抵達吉隆坡機場(KL) → 前往住宿點 → 球場練球
住宿：V Garden飯店（四晚） ⭐️

下榻球場步行10~15分鐘之處，移動方邊。
- 非常潮濕，沒有很整潔
- 但也只是睡覺的地方而已所以接受
- 下次不住

練球時光

遇到認識子齊的香港人(?)，一起打了兩場比賽

晚餐：小夜市⭐️⭐️⭐️

- 不知道那是哪，看起來像夜市就叫小夜市xd
- 吃了紫色飯，蠻喜歡的(但店員聽不懂我在講什麼，幸好有會講馬來語的華人神救援)
- 沒吃飽還吃了泰式炒飯，超級無敵辣🌶️
- 幸好有先點了一杯冰飲料來喝

02
5/08（五）比賽Day
Round 1 - Set B - Lane 28 - 9:45

- 第一場對上印尼的學生(Silampari Petanque Club1)
- 居然是在戶外場，可想而知熱得要死
- 12:0 獲勝!

中間休息了好久，就跑回飯店吹冷氣

Round 2 - Set A - Lane 14 - 14:30

- 第二場遇上地主-馬來西亞代表隊(Malaysia 6)
- 我po的超炸裂，隊友一直上來打jack(哈哈)
- 2:13 薯條啦啊啊啊

後來因為午後雷陣雨的關係，外面場地大淹水，所以賽程被拉長

Round 3 - Set C - Lane 10 - 22:05

- How lucky we are 打到今天最後一輪的比賽（超級晚）
- 本次比賽表現最好的一場～隊友也表現很讚！
- 13:3 獲勝！

03
5/09（六）比賽Day
Round 4 - Set A - Lane 20 - 10:00

- 這次遇到很厲害的青少年(Saeawak_2026_2)
- 遇到大石頭場地不會丟，丟超爛🙀
- 4:12 薯條條

預賽在此告一段落，2勝2敗，以第68名晉級複賽

Best128 - Set A - Lane 31 - 14:30

- 打到去年也有遇到的一個對手，真是有緣～(FELDA2)
- 一開始jack一直出界超鬧，打到最後超級緊張刺激，我們要追兩分才贏
- 後來因為加賽問題溝通半天，手機還過熱打不開影片，反正搞超久
- 13:9獲勝！

Best64 - Set A - Lane 4 - 17:45

- 哇終於打到中間的場地，還有印度隊(INDIA-1)
- 結果被打成智障
- 0:13大薯條

04
5/10（日）看比賽Day

昨天輸掉之後今天就沒得比賽了qq
只好到場邊看其他高手過招!!
(恭喜小鬍子哥打敗肉丸～～Champion!)
子齊還跟馬來西亞和柬埔寨的球友一起打歡樂友誼賽～

晚餐：新峰肉骨茶⭐️⭐️⭐️⭐️

觀光客餐廳（超級貴），但就想吃這一口呀～

05
5/11（一）check out → 商場晃晃 → 抵達台灣
午餐：Memang Meow⭐️⭐️⭐️⭐️

- 最後一天，跑去上次很喜歡的店吃椰奶飯！
- 前幾天吃太多東南亞料理了，有點膩xd

買很多小餅乾、糖果，準備回家啦～～ 子齊在機場試吃榴槤巧克力🙀 我拒絕!!

旅後心得

這趟根本是狂吃711之旅哈哈
感覺還是要練個球再來，不然就像這樣被印度打到像智障
但還是開心呀～出國打比賽超讚!!

4/23（四）抵達樟宜機場(SIN) → 前往住宿點 → 小印度晃晃 → 魚尾獅公園打卡
住宿：米梧槽飯店（三晚）

抵達後直奔飯店放行李。下榻捷運「梧槽站」步行2分鐘之處，移動方邊。

景點一：小印度 ⭐️

- 超多鴿子🐦 ==
- 吃了一個巧克力＆香蕉印度煎餅
- 速速離開

景點二：魚尾獅公園 ⭐️⭐️⭐️

好多人呀，速速打卡拍照

原本想去很有名的濱海灣花園，但有點找不到路，加上真的是太熱啦！於是決定搭Grab吃飯去🍚

晚餐：松發肉骨茶⭐️⭐️⭐️

餓了很久啥都好吃！感覺像胡椒湯(蠻辣的xd)，可以免費續湯

第一天の新加坡心得

實在是太 熱 了 🔥，物價也真是嚇到寶寶😱，害我都不敢狂吃xd

02
4/24（五）環球影城Day!!
早餐：亞坤吐司⭐️⭐️

曹小方指定探店，吐司很酥很好吃，但是咖椰實在是太甜啦…豆漿咖啡喝起來也超甜，無糖的比較好一點

環球影城🌍⭐️⭐️⭐️⭐️⭐️

- 太夢幻了！感覺像進到另一個世界
- 被抓去搭木乃伊室內雲霄飛車和室外的紅色雲霄飛車(這還是搭到最後一趟🙀，因為下午在打雷)，超級大突破！下來快嚇死了，不過似乎沒有我以為的那麼可怕，都是心理恐懼支配。
- 還有很多像小小兵、電影特效片場我都很喜歡～
- 人生第一次吵架居然獻給帶女兒插隊還裝傻的臭老爸☹️

離開園區之後時間還早，我們計劃去哈利波特展區逛逛。不過我對哈利波特沒興趣，就在外面等他們。

晚餐：老巴剎夜市⭐️⭐️

- 買了網路上很多人推薦的沙爹烤串，甜到受不了，只有蝦子比較好吃
- 還買了粿條，也是甜甜q
- 是一個chill chill的觀光勝地

03
4/25（六）牛車水 → Skyline Luge → 濱海灣花園 → 吃螃蟹🦀
早餐：The Populus⭐️⭐️⭐️

小林找了一間咖啡廳說想去吃，後來一陣混亂變成曹小方跟林外帶，沒有滿足林的coffee time，小qq

景點一：牛車水⭐️

- 去唐人街晃晃，最後買了巧克力
- 沒停留很久，就走了

後來決定分開玩

景點二：Skyline Luge 滑坡車⭐️⭐️⭐️⭐️⭐️

- 原本不想玩那麼多趟，想說體驗一下就好，結果售票員超熱情說多送我們一趟
- 第一趟我跟小畢都怕怕的，尤其是坐纜車上去的時候，雙腳懸空🙀
- 後來玩到後面超過癮！超喜歡～
- 就是很熱就是了xd

午餐：Jollobee⭐️⭐️⭐️

去吃東南亞在地的炸雞店，套餐裡還有義大利麵哈哈

後來回飯店換衣服，休息一下(吹冷氣🌬️)

景點三：濱海灣花園夜光秀⭐️⭐️

- 會合之後一起去傳說中必去的景點
- 走了好久好久都沒走到
- 結果看了3分鐘就說要去吃飯haha
- (有點無聊)

晚餐：珍寶海鮮⭐️⭐️⭐️⭐️

- 小畢說想吃螃蟹，必須滿足
- 最後一餐吃大餐～
- 螃蟹真的好讚！(也是蠻辣)

旅後心得

Happy Happy Happy!
好久沒見到小畢＆曹小方！
跟他們一起出去玩很舒服～
我們都會互相照顧對方
希望以後還能一起出去玩！

09/24（三）抵達吉隆坡機場(KL) → 前往住宿點
住宿：Times Square Hotel飯店（五晚） ⭐️⭐️⭐️⭐️⭐️

入住子齊之前隨隊來住的飯店。

- 超級無敵大又美
- 每天早餐都吃飽飽
- 非常喜歡

晚餐：Memang Meow⭐️⭐️⭐️⭐️

- 在飯店樓下隨便亂找
- 椰奶飯超級好吃!!!
- 炒飯也好吃，但是太辣了，辣到燒起來🔥

跑去玩卡丁車，好玩！

02
09/25（四）練球Day
練球時光

- 天啊這個球場也太大太美了吧！
- 還看到去年的世界冠軍-馬達加斯加成員，在當馬來西亞國家隊的教練😮(我們肯定跑去偷聽)
- 跟馬來西亞的球友打了幾場友誼賽

午餐：福香肉骨茶⭐️⭐️⭐️⭐️

- 來馬來西亞肯定要吃一下肉骨茶
-在球場附近找了一間，我覺得好好吃呀！

吃飽之後又跑回去繼續打球～～

練球時光

- 下午之後越來越多人，很多球友找我們一起打友誼賽，一場接一場
- 要走之前，還遇到Ratchata，跑去找他打比賽，結果8分鐘就被剃頭哈哈

晚餐：KAKATOO MALAYSIA⭐️⭐️⭐️

- 餐點是很不錯的，我們喜歡的清淡口味！
- 但怎麼沒人？而且感覺偏貴

03
09/26（五）比賽Day
午餐：香香雞煲飯⭐️⭐️⭐️

- 趁空擋跑到球場附近找飯吃
- 店員超熱情一直跟我們聊天，還推薦我們一定要去雲頂高原玩

Round 1 - Set C - Lane 15 - 14:40

- 第一場比賽遇到馬來西亞人(PENANG 4)，微微緊張
- 11:8 獲勝！

比賽剛準備開時時來了一輛美祿車，聽說是最好喝的美祿，想著比完賽要來去喝。結果!!當我比完賽走過去時，店員說finished。什麼意思……我前面的人剛拿了兩杯欸……我大哭泣。結果到最後一天也沒有再來，再也沒喝到嗚嗚嗚嗚嗚😭

Round 2 - Set A - Lane 20 - 16:30

- 遇到也是馬來西亞人(ATM 1)
- 前面我大當機，從6:0開始追
- 13:6獲勝！

Round 3 - Set A - Lane 17 - 21:30

- 哇！打到今天的末場，已經超級無敵累
- 遇到超厲害的警察隊(PDRM 1)，剛好我們狀態也不太好
- 2:13大薯條

但有偷偷慶幸提早被結束，不然要搞更晚🤫

04
09/27（六）比賽Day
Round 4 - Set A - Lane 16 - 11:40

- 遇到馬來西亞代表隊的女生(MALAYSIA 14)
- 焦灼呀，打到加賽的最後一刻，全世界都在等我們
- 13:12獲勝！

預賽四輪吿一段落啦！

午餐：McDonald’s⭐️

- 相當不好吃
- 我們趁空擋去吃飯＋休息＋吹冷氣，真的很熱！

Best128 - Set B - Lane 22 - 19:50

- 遇上菲律賓代表隊(Philippines 1)，又po又shoot，怎麼打？
- 真的差點輸掉，都想說是最後3顆球了，好好珍惜，結果被送上去
- 11:10獲勝！

Best64 - Lane 27 - 21:40

- 又喜提今天最末場比賽呦！(so crazy)
- 上一場打完已經幾乎耗盡精力，沒想到還有一場！而且還是在不熟悉的戶外場，天啊…幸好隊友有找到吳po蓁使用說明書哈哈
- 遇到馬來西亞代表隊(MALAYSIA 6)
- 12:7獲勝！

打完都已經快11點了，真是沒這麼瘋狂過!!
隔天是一早8點多的比賽，哈哈哈

05
09/28（日）比賽Day
Best32 - Lane 20 - 8:15

- 一早去熱身發現，大家都這麼Chill嗎？開賽前10分鐘才有人來(認真不誇張)
- 遇到馬來西亞當地隊伍(DP STYLE 2)
- 12:10獲勝！

Best16 - Lane 8 - 10:00

- 什麼！居然闖到16強，瘋了吧
- 開賽了對手都沒來，我們想說發生什麼事！結果睏抖就慢慢地走過來??WTF??
- 子齊興奮至極(我還好哈哈)，但我後來就變睏抖粉絲🤫
- 13:11薯條啦

晚餐：Memang Meow⭐️⭐️⭐️⭐️

實在是太喜歡了，又跑去外帶第一天吃過的椰奶飯，好好粗！

輸掉之後覺得可惜，但真的太值得了！
還拿到獎金～～Happy!!
留下來繼續看神仙打架

06
09/29（一）check out → 商場晃晃 → 抵達台灣
早餐：Times Square Hotel飯店Buffet⭐️⭐️⭐️⭐️⭐️

- 最後一天一定要繼續吃爆早餐！
- 體驗了前幾天都不敢拿的印度抓餅和特色煎蛋，超好吃！

退房之後推著行李到隔壁的商場逛逛，最後搭車去機場，準備回家啦！

旅後心得

天啊第一次出國打比賽，沒想到可以打這麼多場！每一場都打75分鐘加一局，打好打滿(除了被警察剃頭那場xd)我從來就沒有打滾球比賽有這麼長時間的，真的超級爽！好值得、好喜歡！以後一定還要來！！！

餓扁了，隨意吃！

03
1/12（日）吃吃吃 → 奉恩寺 → 聖水

每天都很晚睡，也睡到很晚，所以都從午餐開啟每一天哈哈哈

午餐：Obongzip 오봉집 삼성점 ⭐️⭐️⭐️⭐️

ㄌㄌㄈ帶我們去吃一間很好吃的店!! 我最喜歡那個要自己辦的粉絲～超美味！

景點一：星空圖書館⭐️

ig上很紅的景點，但也沒啥，主要還是在商場裡逛街哈哈

景點二：奉恩寺⭐️⭐️

一個寺廟，來走走晃晃～順便幫老媽代購一些迷信小物

景點三：聖水⭐️⭐️⭐️

又來到逛街行程！在Olive Young大爆買xd 還有吃到「自然鹽可頌」，超級爆炸好吃，我給五顆星⭐️⭐️⭐️⭐️⭐️

By the way今天還買了一杯MEGA COFFEE的桃子美式，好喝！但有點甜

04
1/13（一）延世大學 → 弘大 → 樂天超市
景點一：延世大學⭐️⭐️⭐️

去ㄌㄌㄈ的學校逛～～還拍照片哈哈，還去吃學餐!!! 超酷的吧～

下午茶：인마이룸 ⭐️⭐️

去吃漂亮咖啡廳～還幫ㄌㄌㄈ補慶生!!!嘻嘻嘻，想不到吧！Surprise~

景點二：弘大⭐️⭐️⭐️⭐️

個人蠻喜歡弘大的，蠻好逛！已經是妹妹弱腦波刷卡模式第三天xd

晚餐：Donjunam Hongdae Korean BBQ Restaurants ⭐️⭐️⭐️⭐️⭐️

來吃韓式燒烤!!!這間是我最喜歡的一餐～超級無敵好吃，還想再去的那種!!

插曲：有人走路走一走撞到路中間的電線竿，超級大聲….

景點三：樂天超市⭐️⭐️⭐️⭐️

快回家了，去買伴手禮。這趟真的是消費力驚人….哈哈！

宵夜：炸雞⭐️⭐️⭐️

ㄌㄌㄈ請客～她說這比橋春好吃的！好幸福～

05
1/14（二）廣藏市場 → 漢南洞 → 機場
景點一：廣藏市場⭐️⭐️⭐️

- 去吃生牛肉跟生章魚(我不敢吃哈哈)，還吃了白糖粿！
- 然後逛逛街～還有拍拍貼機!!!

景點二：漢南洞⭐️⭐️⭐️

最後的逛街一站～我買了香水，嘻嘻！

回飯店拿行李之後就搭車去機場～～

06
1/15（三）回台灣

- 不知道在想什麼，居然跑去機場大廳睡一晚，累鼠還沒有很舒服，不是說要去汗蒸沐嗎
- 登機前，有人名字打錯，又再刷一筆才上飛機;與此同時，我的行李箱超重，只好在櫃檯開行李……哈哈哈，回家之路一波好幾折

旅後心得

這趟旅行真的要是沒有ㄌㄌㄈ帶著我們該怎麼辦，但我們還是分工明確，負責帶路的、負責找吃的、負責刷卡的xd 還要謝謝娟&雪支持我們出國哈哈！開心喜歡～但韓國真的是不要輕易的去，荷包都瘦了xd
